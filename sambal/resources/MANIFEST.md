# Resources

The engine's lexicons, pattern files and context statistics. All regenerate
from [`generation/`](generation/) (script → source map and pinning status
there) except the context statistics (the stats stage) and the hand-authored
licensor patterns.

- context statistics: [`lemma_stats_top_25k.pkl`](lemma_stats_top_25k.pkl) — lemma/context
  counts over the source corpus, the profile's `ctx_lemma_stats_path`; regenerated by the
  stats stage ([Guide 3.3](../../reproduce/icml2026/DATA.md#33-context-statistics)), whose
  counts depend on the parser build — the ICML 2026 paper's corpus used the committed file
- countability classes: [`count.txt`](count.txt), [`mass.txt`](mass.txt), [`both.txt`](both.txt),
  [`pluralia_tantum.txt`](pluralia_tantum.txt) — derived from the English Wiktionary (Kaikki/
  Wiktextract dump; Wiktionary content is CC BY-SA 3.0 + GFDL)
- WordNet-derived lemma lists: [`wordnet_nouns.jsonl`](wordnet_nouns.jsonl),
  [`wordnet_adjectives.jsonl`](wordnet_adjectives.jsonl),
  [`wordnet_adverbs.jsonl`](wordnet_adverbs.jsonl) (WordNet License)
- vocabulary gates: [`allowed_vocab.txt`](allowed_vocab.txt) (spaCy token counts over the BabyLM
  2024 10M-word train split) and
  [`allowed_proper_nouns.txt`](allowed_proper_nouns.txt) (from that vocabulary and a
  proper-noun-retaining statistics run that is not shipped —
  [`generation/README.md`](generation/README.md))
- function words: [`function_words_ud_ewt.txt`](function_words_ud_ewt.txt)
  (UD_English-EWT, CC BY-SA 4.0)
- NPIs and licensors: [`english_npis_wiktionary.tsv`](english_npis_wiktionary.tsv) (Wiktionary),
  [`licensor_patterns_full.jsonl`](licensor_patterns_full.jsonl) (hand-authored; no script)
- multi-word expressions: [`fixed_mwes_all.txt`](fixed_mwes_all.txt),
  [`streusle_vmwe_patterns.jsonl`](streusle_vmwe_patterns.jsonl)
  (STREUSLE-derived, CC BY-SA 4.0)
- to-infinitive lexicons: [`toinf_verbs.jsonl`](toinf_verbs.jsonl),
  [`toinf_adjs.jsonl`](toinf_adjs.jsonl)
  (English Resource Grammar via ACE)
- names and human/gender lexicons: [`given_names_ssa.txt`](given_names_ssa.txt),
  [`male_given_names.txt`](male_given_names.txt),
  [`female_given_names.txt`](female_given_names.txt),
  [`neutral_given_names.txt`](neutral_given_names.txt) (SSA baby-name data,
  US public domain), [`human_nouns.jsonl`](human_nouns.jsonl) (WordNet),
  [`gendered_words_filtered.json`](gendered_words_filtered.json)
  (ecmonsen/gendered_words, CC BY 3.0)
- benchmark-vocabulary gate for the `blimpvocab_flat` corpus variant:
  [`blimpvocab.txt`](blimpvocab.txt) (the BLiMP item vocabulary)
