# entropy

Word-level lexical entropy of a corpus: [`lexical_entropy.py`](lexical_entropy.py)
is the counting and estimation engine, [`matched_budget.py`](matched_budget.py)
runs it on the ICML 2026 paper's three corpora at one common token budget ([Guide 3.10](../../reproduce/icml2026/DATA.md#310-entropy-record--table-10)).
